# 🏒 NHL Salary Prediction Dashboard

Predicting NHL player salaries using advanced regression models (Ridge & Lasso).  
This project combines data science, machine learning, and visualization to identify  
overpaid and underpaid players based on 2024–25 season performance.

---

## 📊 Key Features
- Clean data pipeline (Pandas, NumPy)
- Ridge vs Lasso regression with cross-validation
- Rookie vs Veteran model comparison
- Position-based predictive performance (C, LW, RW, D)
- Interactive visualizations (coming soon via Plotly Dash)
- Top 10 overpaid / underpaid players by position

---

## 🧠 Technologies
- **Python**: Data analysis, feature engineering, model training  
- **scikit-learn**: Ridge & Lasso regression  
- **Seaborn / Matplotlib**: Visual analytics  
- **Plotly Dash (in progress)**: Interactive dashboard  
- **GitHub / Render / Streamlit Cloud**: Deployment and hosting
